Install Valvet

Native binaries. No Valvet runtime. No garbage collector.

Your first Valvet program

Build the compiler, run a script, then follow the same path into data work. This guide targets Valvet 0.5.0.

About 10 minutesStable Rust + a C compilerVersion 0.5.0

Before you start

Install stable Rust and a C compiler. Valvet uses Rust to build its compiler and a system C compiler to turn generated C11 into a native executable. Set VALVET_CC if the C compiler is not discoverable as cc or gcc.

In a terminal, confirm that cargo --version and cc --version work.

1. Get the source and build

Clone the project, move into its directory, and build the workspace:

git clone https://github.com/Kenneth-Cho-InfoSec/Valvet.git
cd Valvet
cargo build --workspace

The compiler is created at target/debug/valvet. The first Rust build may take a few minutes.

2. Run the included program

The repository includes a hello-world example. Run it through Valvet:

./target/debug/valvet run examples/hello.valvet

Expected output:

hello, valvet

run compiles the source through C11, executes the resulting native program, and returns its exit status.

3. Write a small analysis

Save this as mean.valvet in the repository root. It uses a vector, a loop, and a function; the cast makes the division explicit.

fun mean(values: Vec<Float64>): Float64 {
    var total = 0.0
    for (value in values) {
        total += value
    }
    total / (values.len() as Float64)
}

println(mean(vec![2.0, 4.0, 6.0, 8.0]))

Run it with ./target/debug/valvet run mean.valvet. It prints 5. Check without linking by using ./target/debug/valvet check mean.valvet.
