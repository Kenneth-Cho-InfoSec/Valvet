Safe. Fast. Small.

Every part of Valvet serves the same goal: analysis that compiles to one native binary you can reason about. No interpreter. No collector. No runtime to deploy.

Safe

Borrow-checked references, tracked ownership, and errors that never panic the compiler. Each diagnostic carries file, position, code, and help.

prog.valvetE0205
error[E0205]: cannot assign through this place
  (immutable binding or shared reference)
  --> prog.valvet:3:5
  help: use `var` bindings and `&mut` for mutation

Memory bugs that slip through testing in scripting languages are compile errors here.

Fast

Tight loops over vectors run at C speed, with no interpreter and no collector pauses.

Small

One coherent core: vectors, structs, enums, pattern matching, modules. Programs read like the analysis they express, and there is little syntax to learn before you are productive.

The 0.2.0 foundation

Units

Annotate numbers with @m, @s, @km/h. Dimensions check at compile time; compatible scales convert silently.

Frames

CSV in, grouped means and audited joins out. Missing cells stay explicit, and every join reports what matched.

Autodiff

Dual-number forward differentiation with a seed helper. Write the loss once, read the gradient.

Parallel

par_sum splits vectors across threads deterministically. Same input, same bits, every thread count.

import std::frame::DynamicFrame;
import std::sql::sql;

val f = DynamicFrame { names: vec!["region", "sales"], cols: vec![vec!["east", "west", "east", "west"], vec!["10", "20", "30", "40"]], nrows: 4 as Int64 };
let Ok(q) = sql(&f, "SELECT region, SUM(sales) FROM f GROUP BY region ORDER BY region") else {

    return 1;
};

The query plans down to frame verbs, so results match the verb form exactly. Anything outside the subset is a compile-time error.

Four stages.
One translation unit.

The frontend checks everything before any C is emitted. The C compiler handles only the last mile.

An annotated syntax tree, with exact spans.

The parser keeps file, line, and column on every node. Nothing is guessed, and every later error can point to the character that caused it.
