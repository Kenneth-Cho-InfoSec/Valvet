Valvet

A small, safe, compiled language for data work. Native binaries, no garbage collector, no runtime.

Get Started Install

Why Valvet

Safe

Borrow-checked references, tracked ownership, and errors that never panic the compiler. Each diagnostic carries file, position, code, and help. Memory bugs that slip through testing in scripting languages are compile errors here.

Fast

Compiles through C11 to native binaries. Tight loops over vectors run at C speed with no interpreter and no collector pauses. A 3000-sweep model fit over real data finishes in a tenth of a second.

Small

One coherent core: vectors, structs, enums, pattern matching, modules. Programs read like the analysis they express, and there is little syntax to learn before you are productive.

Thirty seconds

Input · Valvet
fun mean(v: Vec<Float64>): Float64 {
    var total = 0.0
    for (x in v) {
        total += x
    }
    total / (v.len() as Float64)
}

fun main() {
    println(mean(vec![2.0, 4.0, 6.0, 8.0]))
}

How programs run

1. Parse

Source becomes an annotated syntax tree with exact spans.

2. Check

Types resolve, then the borrow checker approves every reference.

3. Lower

Checked code lowers to readable C11 with deterministic frees.

4. Link

A plain C compiler produces a dependency-free native binary.

Bash
# clone the repo, then
cargo build --release
./target/release/valvet run hello.valvet
