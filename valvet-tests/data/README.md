# Fixture data provenance

This directory holds small, deterministic fixtures used by the typed-frame
and binary-format tests. Nothing here is production data.

The Parquet and Arrow files are generated by checked-in Python scripts that
use only the Python standard library:

```sh
python3 scripts/make_parquet_fixtures.py
python3 scripts/make_arrow_fixtures.py
```

Both scripts write the exact bytes below. Re-running them should leave the
tree unchanged. The malformed fixtures (`*_truncated`, `*_bad_offset`,
`*_nested`, `*_dictionary`, and `*_unsupported`) are intentionally invalid or
outside the supported subset; they exist to prove that readers return
controlled errors rather than crashing.

The typed CSV and JSON fixtures are hand-written inputs for the strict,
lenient, and schema-inference tests.
